## Non-negotiable controls

- Task Contract remains the permission ceiling; phase escalation is retryable
  and cannot widen declared scope.
- Hooks are deterministic and fail closed for the current tool call; a missing
  checker is warning plus Evidence, not silent success or infrastructure crash.
- Context conflicts at the same scope block; precedence is explicit and
  directory legacy exceptions are testable.
- Consolidation never deletes raw Evidence and a no-new-content cycle is a
  recorded legal no-op.
- `danger` commands remain permanently blocked even when Task permissions or
  a user approval would otherwise allow them.
- Progressive tool exposure is capability-driven and ordered with remote tools
  last. Worker messages can wake the Controller but cannot carry state truth.
- No T13 files, batch implementation or parallel merge path is introduced.
