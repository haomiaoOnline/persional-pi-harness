## 3. Known-Upstream-Failure gate

`npm run check` remains intentionally honest and surfaces the inherited failure:

```text
packages/ai/src/api/google-shared.ts(402,10): error TS2322:
Type 'FinishReason.TOO_MANY_TOOL_CALLS' is not assignable to type 'never'.
```

The normal `.husky/pre-commit` flow runs `node
scripts/known-upstream-failure-gate.mjs --allow-known-upstream-failure` only
after the normal check returns this failure. It does not globally disable the
hook and no v3.1 commit used `--no-verify`.

The allowlist is exact and includes:

| Field | Value |
| --- | --- |
| package | `@earendil-works/pi-ai` |
| file / line | `packages/ai/src/api/google-shared.ts:402` |
| code | `TS2322` |
| semantic message | `Type 'FinishReason.TOO_MANY_TOOL_CALLS' is not assignable to type 'never'.` |
| source needle | `const _exhaustive: never = reason;` |
| pinned upstream revision | `71dca871bc80b6bc97be37f0ca3189399d651fff` |
| source digest | `sha256:fa9a45177b6c1e1636b8b1ef4c8b332e903e4b379039cb1bacbbc312a8e1662d` |

The gate verifies package identity, file/code/message/source needle, pinned
revision and digest; materializes the pinned revision with `git archive` so it
does not mutate the main index; installs the pristine archive; reproduces the
exact diagnostic; then requires PPH build, core tests, Personal PI regression
and protocol-isolation proof. It writes an auditable Decision/Evidence JSON
under `.git/pph-known-upstream-failure-gate/`.

Actual proof:

- normal static checks before the error: formatting, dependencies, imports,
  entry graphs, locks and browser smoke all pass;
- exact gate test: `node --test scripts/known-upstream-failure-gate.test.mjs` →
  `6/6` pass;
- script suite: `npm run test:scripts` → `29/29` pass;
- each v3.1 commit ran the normal hook and generated a successful exact-gate
  Decision/Evidence record;
- any new diagnostic, changed semantic message, revision drift or source-digest
  drift fails closed because it cannot match the single allowlist entry.

This is an auditable override for one inherited failure, not a green
repository-wide check and not permission to edit upstream.
