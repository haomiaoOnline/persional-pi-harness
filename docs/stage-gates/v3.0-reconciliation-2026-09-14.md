## A2 v3.0 boundary corrections

只对当前 v3.0 closure 发现的边界做了最小修复，没有实现 v3.1 功能：

1. Pipeline 现在校验 Result 的 \`task_id\`、\`run_id\`、\`worker_id\` 和 \`lease_epoch\`；跨执行的结构合法结果会被转换为绑定到当前 Run 的 failure。
2. Worker adapter 获得显式的 model/tool admission controls；\`PiWorker\` 将嵌套模型调用的预算耗尽向上交给 Pipeline，使 Task 进入 \`BLOCKED\`。未使用 admission controls 的外部 adapter 仍不自动获得内核可观测性，不能据此宣称真实 Provider 已受控。
3. 使用同一 Persistent State Store 的多个 LeaseManager 按条目更新租约、从持久状态读取当前 fencing 事实，并保留单调 epoch；旧 lease 无法删除或接受新的 lease。
4. 分解预算持久化实际 admission 的 \`open_tasks\`；Recovery 只决定下一动作，下一次 Run 的 \`startRetry\` 才创建 replacement Lease，消除 READY 间隙中的无 Run 活动 Lease。
5. Recovery Result admission 同时绑定当前 Run、Worker 和 lease epoch。
